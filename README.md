# adrian.dev

Personal portfolio of **Adrian Akhuya** — Full Stack Developer.

A clean, dark-themed portfolio showcasing my work, skills, and projects. Built with modern web technologies and a focus on performance, accessibility, and thoughtful design.

---

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **React Icons** / **Lucide React**

---

## Features

- Responsive, mobile-first design
- Interactive developer terminal with command history and autocomplete
- Animated hero with typing effect
- Project showcase
- Contact section with direct email, LinkedIn, and call links
- Custom 404 page
- Section glow on scroll
- Subtle mouse-following glow on desktop

---

## Getting Started

Install dependencies:

    npm install

Run development server:

    npm run dev

Build for production:

    npm run build

Start production server:

    npm start

Open http://localhost:3000 in your browser.
